# Inbox

Put a file here and push it to `main`: the **Run a file** workflow works out
what it is and opens it on the one system that can run it. The results
(a picture and a short note per file) are in the run's `gimmich-run-report`
download.

GitHub only takes files up to 100 MB here. For bigger files (like a disc
image), use **Actions → Run a file → Run workflow** and paste a download link.

This repository is public: don't put private files here.
